\section*{Аннотация}

В данной работе рассматривается задача оптимизации поиска базовых чанков в системах дедупликации данных на основе сходства (Similarity-Based Chunking, SBC). Для эффективного поиска похожих блоков данных используется инвертированный индекс, хранящий признаки (features/sketches) чанков. Однако при больших объемах данных обход списков инвертированного индекса (posting lists) становится узким местом системы по времени выполнения и потреблению оперативной памяти.

Для решения этой вычислительной проблемы в работе исследуется и реализуется набор поисковых эвристик в рамках подсистемы \texttt{marline\_index}. В частности, применяются следующие оптимизации: фильтрация высокочастотных признаков (\texttt{max\_df}), оптимизация порядка обхода признаков от редких к частым (\texttt{rare\_first}), раннее отсечение кандидатов, не достигающих заданного порога сходства Жаккара (\texttt{min\_jaccard}), а также использование механизма обратной связи для штрафования ложноположительных кандидатов (\texttt{fp\_metric\_threshold}).

Цель работы — разработка эвристических алгоритмов обхода индекса, которые позволят существенно ускорить процесс выбора оптимального базового чанка (top-k) без заметного снижения итогового коэффициента дельта-компрессии. Ожидаемым результатом является программная реализация предложенных эвристик на языке Rust в проекте \texttt{marline}, а также оценка их влияния на производительность подсистемы поиска с помощью тестирования на репрезентативных наборах данных.
